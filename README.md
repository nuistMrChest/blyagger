# BLYAGGER!!!!!!!

## A static site generator for my personal blog: blyag.icu

This app works only on linux and can only be used in maintaining my blog,

The blog i wanted to be uploaded must be named "origin.txt", with directory named "img" comtaining 1.png, 2.png and so on.

Inside origin.txt, the first line will be treated as the title.

Then, "@" will be replaced with image from img.

The first @ will be 1.png, second one be 2.png, and so on.

Finally, code should be contained by "<" ">".

That's all.
